# Um link quebrado não precisa encerrar a visita

## Objetivo

Explicar que uma página de erro 404 pode reconhecer que o endereço não foi encontrado e oferecer caminhos úteis para o visitante continuar, sem esconder o erro técnico dos mecanismos de busca.

## Configuração da publicação

- **Formato:** imagem única
- **Arquivo:** `imagem.jpg`
- **Dimensão:** 1080 × 1350 px
- **CTA:** incentivar a revisão de links antigos e da experiência oferecida pela página 404

## Legenda pronta

Um produto sai de linha, uma página muda de endereço ou alguém digita o link errado. Se o site responde apenas com uma tela vazia, a visita pode terminar ali.

Uma página 404 útil pode:

- dizer com clareza que o endereço não foi encontrado
- manter a identidade visual do negócio
- oferecer links para início, serviços ou contato
- permitir uma busca, quando isso fizer sentido para o site

Existe também uma diferença técnica importante: se o conteúdo mudou definitivamente de endereço, o caminho correto costuma ser um redirecionamento permanente. Se ele realmente não existe, o servidor deve retornar o status 404, mesmo que a tela tenha um desenho personalizado.

O Google recomenda páginas 404 personalizadas que ajudem pessoas a localizar a informação procurada e a explorar outras áreas do site. Uma tela bonita não deve se transformar em um “soft 404” que responde como se tudo estivesse normal.
